## 🚀 Buka Presentasi

### 1. Langsung Lewat Browser (GitHub Pages)
🔗 **[fzz90.github.io/kanji-tetsu.github.io](https://fzz90.github.io/kanji-tetsu.github.io/)**

### 2. Jalankan Secara Lokal
Buka folder proyek ini di terminal, lalu jalankan:

```powershell
python -m http.server 4174 --bind 127.0.0.1
```

Kemudian akses melalui browser di `http://127.0.0.1:4174` atau cukup klik dua kali pada file `index.html`.

## 📑 Struktur & Isi Slide

1. **Slide 1 — Pembuka & Identitas**:
   - Judul: Kanji 鉄 (*TETSU*).
   - Identitas: Faiz Syihab · NIM 125241046 · Kelas A.
   - Peribahasa Jepang: *Tetsu wa atsui uchi ni ute* (鉄は熱いうちに打て — Tempalah besi selagi panas).
2. **Slide 2 — Bushu & Yomikata**:
   - Bushu: 釒 / 金 (*kanehen* / かねへん, Radikal #167, posisi kiri/hen).
   - On-yomi: **テツ** (*TETSU*).
   - Kun-yomi: **くろがね** (*kurogane* — arti puitis "besi hitam").
3. **Slide 3 — Kakusuu & Animasi Cara Menulis**:
   - Kakusuu: **13 画** (8 goresan radikal kiri + 5 goresan bagian kanan).
   - Animasi goresan interaktif SVG (berbasis KanjiVG) dengan kontrol *Putar*, *Ulangi*, dan *Langkah demi langkah*.
4. **Slide 4 — Oboekata (Cara Mengingat)**:
   - Komponen utama: Kanji **金** (*kin* - logam/emas) dan **矢** (*ya* - panah).
   - Mnemonic: *"Besi adalah Logam (金) yang melesat kuat seperti Panah (矢)"*.
   - Trivia logo JR (鉃) yang sengaja mengganti bagian kanan menjadi 矢.
5. **Slide 5 — Jukugo (Kosakata Gabungan)**:
   - 鉄道 (*tetsudou* - Kereta api)
   - 地下鉄 (*chikatetsu* - Kereta bawah tanah)
   - 鉄分 (*tetsubun* - Zat besi)
   - 私鉄 (*shitetsu* - Kereta swasta)
   - 鉄板 (*teppan* - Pelat besi / teppan)
   - 鋼鉄 (*koutetsu* - Baja)
6. **Slide 6 — Contoh Kalimat (例文)**:
   - 4 kalimat kontekstual dengan ruby (furigana) dan terjemahan bahasa Indonesia lengkap.
7. **Slide 7 — Penutup**:
   - Ucapan *Arigatou gozaimasu* (ありがとうございました), ringkasan kanji, dan identitas presenter.

## 🎮 Kontrol Navigasi

- **Tombol Panah Kanan / Kiri**, **PageDown / PageUp**: Berpindah antar slide.
- **Home / End**: Langsung ke slide pertama / terakhir.
- **Tombol F**: Masuk atau keluar mode layar penuh (*fullscreen*).
- **Layar Sentuh (Smartphone / Tablet)**: Usap horizontal (*swipe*) ke kiri / kanan.

## 🖨️ Ekspor Cetak / PDF

CSS print telah disiapkan untuk rasio **16:9** ukuran **320 mm × 180 mm**.
Untuk mencetak / simpan PDF:
1. Tekan `Ctrl + P` di browser.
2. Pilih Destination: **Save as PDF**.
3. Centang opsi **Background graphics**.
4. Hilangkan centang pada Header & Footer browser.
